# WordPress com Docker e OpenLiteSpeed (OLS)

Este repositório contém arquivos de configuração para executar o WordPress em um ambiente Docker, utilizando o servidor web OpenLiteSpeed (OLS). Essa configuração oferece uma alternativa leve e performática ao tradicional Apache ou Nginx.

## Pré-requisitos

Certifique-se de ter o Docker e o Docker Compose instalados em sua máquina. Você pode encontrar as instruções de instalação para sua plataforma nos links abaixo:

- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)

## Como usar

1. **Clone o repositório:**

```bash
git clone [https://github.com/marviorocha/OpenLiteSpeed-wordpress.git](https://www.google.com/search?q=https://github.com/marviorocha/OpenLiteSpeed-wordpress.git)
cd OpenLiteSpeed-wordpress
```
